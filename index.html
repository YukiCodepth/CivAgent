Software

A real app for the work before agents touch production.

CivAgent Desktop separates the company product site from the operating workspace. The app launches a local API, manages required integrations, runs the organization agent, and keeps sensitive keys out of the website.

01

Desktop workspace

Company intake, agent execution, sources, tool calls, artifacts, saved runs, and audit logs live in the app.

02

Local backend

Electron starts a local Python sidecar on 127.0.0.1 and loads the workspace only after health checks pass.

03

Required integrations

Gemini, Tavily, Supabase, Firecrawl, Composio, and E2B must all be ready before the Run button unlocks.

04

Evidence package

Every completed run includes provider status, sources, sandbox analysis, Supabase sync, and exportable reports.

Security posture

Keys stay local. Completed evidence becomes auditable.

The desktop app stores provider settings in the user-data directory and shows masked readiness. Successful runs require Supabase persistence before CivAgent marks the report completed.

Local

Desktop key store

Integration values are saved outside the repository and never rendered in full inside the interface.

Agent

Strict readiness gate

Runs stop with clear errors when any required provider is missing or fails.

Cloud

Supabase record

Runs, artifacts, sources, tool calls, approvals, and audit evidence sync before completion.

Export

Company report

Generated reports include provider status, evidence, approvals, and operating artifacts.
