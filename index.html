The operating layer for agentic companies.

Architecture

A real product foundation, not just a front-end concept.

The current CivAgent build includes the product website, browser workspace, product API, real agent endpoint, external tool adapters, SQLite evidence store, mandatory Supabase sync, audit log, export endpoint, Dockerfile, and deployment documentation.

Frontend

Website + workspace

Responsive HTML, CSS, and JavaScript interface with integration status, trace panels, sources, approvals, and synced artifacts.

Backend

Python agent API

Standard-library HTTP server with real agent runs, external API calls, static serving, validation, and security headers.

Persistence

SQLite + Supabase

Stores completed evidence locally after agent runs, artifacts, sources, tool calls, and approvals sync to Supabase.

Delivery

Docker-ready runtime

Container configuration, environment example, deployment guide, and health endpoint for evaluation environments.
